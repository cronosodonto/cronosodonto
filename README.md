# Cronos Odonto

Sistema de gestão comercial e financeira desenvolvido para clínicas odontológicas.

## Principais recursos

- Gestão de leads e pacientes
- Funil comercial e acompanhamento de oportunidades
- Cadastro de avaliações e tratamentos
- Controle de recebimentos e parcelamentos
- Baixas, antecipações e histórico financeiro
- Dashboard com indicadores comerciais e financeiros
- Gestão de campanhas, tarefas e usuários
- Painel Superadmin para administração das clínicas

## Estrutura

- `/app` — aplicação principal
- `/login` — autenticação
- `/superadmin` — painel administrativo
- `/assets` — estilos, scripts e recursos visuais

## Tecnologias

- HTML, CSS e JavaScript
- Supabase
- PostgreSQL
- GitHub Pages

## Segurança

O sistema utiliza autenticação, isolamento de dados por clínica e políticas de acesso no banco de dados. Informações sensíveis e credenciais não devem ser adicionadas diretamente ao repositório.

## Implantação

O conteúdo da pasta principal deve ser publicado na raiz do repositório configurado para o domínio do Cronos Odonto.

O arquivo `CNAME` deve ser preservado para manter o domínio personalizado.
